# আমার হিসাব — Netlify ডিপ্লয়

1. এই ফোল্ডারটি GitHub-এ আপলোড করুন (বা `npm i -g netlify-cli` দিয়ে `netlify deploy --prod`)।
2. Netlify → Add new site → Import from Git → এই রিপো বেছে নিন। বিল্ড সেটিং আলাদা কিছু লাগবে না।
3. ডেটাবেস (Netlify Blobs) নিজে থেকেই সাইটের সাথে যুক্ত হয়। কোনো সেটআপ নেই।
4. সাইট খুলে সবার আগে যে অ্যাকাউন্ট খুলবেন সেটাই অ্যাডমিন।
   (চাইলে Netlify → Environment variables-এ ADMIN_EMAIL দিতে পারেন।)
